Render DataviewJS blocks with the same markup Dataview produces in Obsidian (`div.block-language-dataviewjs`, `<h2><span>…</span></h2>`, …), run scripts in their own context with Obsidian's prototype extensions (`"…".contains()`, `[].last()`, …), make `requestUrl` reject on HTTP errors like Obsidian does, render strings as markdown, and add `dv.el`, `dv.span`, `dv.list` and `dv.table`.
